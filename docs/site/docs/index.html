البيانات التي نجمعها

لا نجمع أي بيانات شخصية عن المستخدمين.

  • لا نطلب تسجيل دخول ولا نستقبل بيانات من أي مستخدم.
  • لا نستخدم ملفات تعريف الارتباط ولا أدوات التتبّع.
  • لا نصل إلى قوائم الأصدقاء ولا الرسائل ولا الملفات الشخصية.

يستخدم التطبيق رمز وصول خاصًا بصفحة «الموجز» يملكه مالك الصفحة وحده، وذلك لغرضين فقط: نشر المنشورات، وقراءة إحصاءات التفاعل مع منشورات الصفحة نفسها (عدد الإعجابات والتعليقات والمشاركات) لتحسين المحتوى.

مصادر المحتوى

ينقل التطبيق أخبارًا منشورة علنًا في خلاصات RSS لمؤسسات إعلامية، ويعيد صياغتها بالعربية. يُذكر اسم المصدر ورابطه في كل منشور، ولا تُنسخ نصوص الناشرين حرفيًا.

التخزين والاحتفاظ

  • تُخزَّن المسودات والصور في مستودع المشروع الخاص بمالك الصفحة.
  • لا تُخزَّن أي بيانات تخص زوار الصفحة أو المتفاعلين معها.
  • إحصاءات التفاعل تُحفظ بصيغة مجمّعة بلا هوية أي شخص.

المشاركة مع أطراف ثالثة

لا نبيع أي بيانات ولا نشاركها. يتصل التطبيق بواجهة فيسبوك (Graph API) للنشر، وبواجهة Anthropic لصياغة النصوص بالعربية. لا تتضمن هذه الاتصالات أي بيانات شخصية عن المستخدمين.

حقوقك

لأنّنا لا نجمع بيانات شخصية، لا توجد بيانات تخصّك لطلب الاطلاع عليها أو حذفها. إن رأيت محتوى يخصّك ونُشر على الصفحة وتريد إزالته، راسلنا وسنستجيب خلال سبعة أيام.

حذف البيانات

لطلب حذف أي بيانات مرتبطة بالتطبيق، راسلنا عبر رسائل صفحة «الموجز» مع ذكر الطلب صراحةً.
